# bedops
Small compatibility-focused container for `bedops`.

## how to use
```bash
docker run --rm -v "$(pwd):/data" docker.io/picotainers/bedops:latest --help
```

## Quick Usage

```bash
# Pull the image
docker pull docker.io/picotainers/bedops:latest

# Run the tool
docker run --rm docker.io/picotainers/bedops:latest bedops --help
```
